# Mini Project Tracker

A full-stack DevOps learning project built with:

- React (Vite)
- Node.js + Express
- PostgreSQL
- Prisma
- Docker
- GitHub Actions
- Terraform
- K3s (planned)
- Prometheus/Grafana/Loki (planned)
